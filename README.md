# Object Detection Annotation Project

## 📌 Project Overview

This project demonstrates an object detection dataset prepared using bounding-box annotations in YOLO format.

The dataset contains vehicle images with annotations for three object classes:

- 2-wheeler
- 4-wheeler
- 6-wheeler

The project focuses on understanding image annotation, bounding boxes, class labeling, and YOLO annotation format.

## 🎯 Project Objectives

- Understand object detection annotation
- Work with bounding-box labels
- Prepare image datasets for machine learning
- Understand YOLO annotation format
- Organize images and corresponding label files
- Practice dataset preparation for AI/ML applications
